NOTEBOOK EXECUTION SEQUENCE
===========================

Current workflow uses a strict 5-step sequence.

QUICK REFERENCE
---------------
STEP 1 (Required) -> Data Ingestion (start here)
STEP 2 (Required) -> Compute Features
STEP 3 (Required) -> Feature Engineering + Labels
STEP 4 (Required) -> All Models Training
STEP 5 (Recommended) -> Model Comparison and Evaluation

OPTIONAL ENHANCED FEATURE PASS
------------------------------
Run this after STEP 3:

python apply_enhanced_features.py

Then use enhanced feature outputs in STEP 4 and STEP 5.

FILE NAMES
----------
STEP_1_Data_Ingestion_Pipeline.ipynb
STEP_2_Compute_Features.ipynb
STEP_3_Feature_Engineering_Labels.ipynb
STEP_4_All_Models_Training.ipynb
STEP_5_Model_Comparison_And_Evaluation.ipynb

RUNTIME ESTIMATES
-----------------
STEP 1: ~10-15 min
STEP 2: ~5-10 min
STEP 3: ~15-20 min
STEP 4: ~15-30 min
STEP 5: ~10-20 min

See notebooks/README.md for detailed notes.
