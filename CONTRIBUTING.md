# Contributing

Thanks for contributing! A short checklist to get started:

- Run tests locally: `PYTHONPATH=. pytest -q`.
- Keep data files (under `data/` and `data_cache/`) out of commits.
- Open a PR with a clear description of your change and tests/examples.

If you want to propose major changes (new features, refactorings), please open an issue first so we can discuss scope and design.
